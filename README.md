# DL NURE Attendance

Автоматически нажимает «Відмітитися» на dl.nure.ua — через 30 минут после начала каждой пары.

## Как работает

1. **План.** 5 раз в день (05:05, 08:05, 11:05, 14:05, 17:05 по времени телефона) и после перезагрузки
   скрипт берёт из календаря DL все занятия «Відвідування» на ближайшие 36 часов
   (`core_calendar_get_calendar_monthly_view` — точное время начала и длительность) и записывает
   в crontab по одной проверке на пару: **начало + 30 минут**. Если телефон включили посреди пары —
   проверка ставится на ближайшую минуту. При изменении плана в Telegram приходит беззвучное 📅.
2. **Проверка** (`--only <id модуля>`): открывает журнал только этого предмета, ищет кнопку
   `a.btn-primary` → `attendance.php?sessid=…` (ссылку «Повідомити про майбутню відсутність» не трогает).
   Авто-статус — отметка сразу; форма со статусами — выбирает «Присутній».
   Затем перезагружает журнал и проверяет, что кнопка исчезла.
3. **Telegram:** ✅ отмечено / ✋ нужно вручную (QR-код или пароль преподавателя) / ❌ ошибка — со звуком;
   🔍 «кнопки нет» и 📅 план — без звука.

Время пар берётся в часовом поясе Киева и переводится во время устройства — в Германии это −1 час.
Смещение можно поменять: `ATTENDANCE_OFFSETS=30` (или `30,60` — две проверки на пару).

## Где запускать

dl.nure.ua закрыт AWS WAF: с IP дата-центров (GitHub Actions, облака, VPS) вместо сайта приходит
страница «Human Verification» (HTTP 405). С домашнего/мобильного интернета проверки нет — поэтому
скрипт запускается на своём устройстве: **Android-телефоне (рекомендуется, он онлайн 24/7)** или ПК.

## Установка на Android (Termux)

1. Из **F-Droid** (не из Play Market — там другая подпись):
   [Termux](https://f-droid.org/packages/com.termux/) и [Termux:Boot](https://f-droid.org/packages/com.termux.boot/).
   Play Защита предупредит «разработано для старой версии Android» — «Все равно установить».
   Termux:Boot открой один раз.
2. Настройки → Приложения → **Termux** → Батарея → **Без ограничений**
   (Xiaomi/Samsung: ещё «Автозапуск»). Без этого Android усыпит cron.
3. В Termux:
   ```
   pkg install -y git
   git clone https://github.com/Farus256/DL_AutoScript
   cd DL_AutoScript
   bash termux/setup.sh
   nano .env
   termux/run.sh --plan --apply
   crontab -l
   ```
   Обновление уже установленного: `cd DL_AutoScript && git pull && bash termux/setup.sh && termux/run.sh --plan --apply`.

### После перезагрузки / полного выключения

Ничего делать не нужно: Termux:Boot при старте телефона включает wake lock, запускает cron и через минуту
перестраивает план. Признак, что всё живо, — уведомление Termux в шторке.
Если уведомления нет (прошивка заблокировала автозапуск) — просто открой Termux: `.bashrc` поднимет cron,
затем `termux/run.sh --plan --apply`. Проверить: `pgrep -x crond` должен вывести число.

### Нагрузка на телефон

- Запусков в день: 5 планов + по одному на пару (было 52 полных обхода).
- Трафик: план ≈ 0,3 МБ (вход + JSON календаря), проверка пары ≈ 0,5 МБ. Раньше каждый обход тянул ~2 МБ HTML.
- Основной расход батареи — не cron, а **wake lock**: он не даёт процессору уснуть. На зарядке это неважно.
  Если телефон на батарее и расход заметен (Настройки → Батарея → Termux) — `termux-wake-unlock`,
  но тогда Android может откладывать проверки на время глубокого сна.

Полезное:
```
crontab -l                 # расписание и план проверок
tail -n 30 attendance.log  # последние запуски
termux/run.sh --plan       # показать план, не записывая
```

### Почему не все предметы

Отмечаются только предметы, где у студентов есть видимый модуль «Відвідування» с самоотметкой.
Осень 2026: Гібридні загрози, Комп'ютерний зір, Обчислювальний інтелект, Теоретичні основи CS.
Нет модуля: «Сучасні напрямки ШІ», «Фізичне виховання» (там тесты к лекциям).
«Технології проєктування інтелектуальних систем» — модуль есть, но скрыт от студентов.
Если преподаватель откроет журнал позже, план подхватит его сам через календарь.

## Установка на ПК (Windows)

1. Python 3.10+ с [python.org](https://www.python.org/downloads/) — при установке отметь **Add python.exe to PATH**.
2. Склонируй/скачай репозиторий в папку, например `D:\DL_NureAttendance`.
3. Создай `.env` по образцу `.env.example`:
   ```
   NURE_USERNAME=логин
   NURE_PASSWORD=пароль
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_CHAT_ID=412345678
   ```
4. Проверка (в этой папке, в терминале):
   ```
   py -m pip install -r requirements.txt
   py nure_attendance.py --dry-run
   ```
   Должен вывести курсы, а в Telegram придёт беззвучное 🔍 или 🧪.
5. Расписание: правый клик по `install_task.ps1` → **Выполнить с помощью PowerShell**
   (или `powershell -ExecutionPolicy Bypass -File install_task.ps1`).
   Задача «NURE attendance»: Пн–Сб, 06:00–19:00 по немецкому времени (= 07–20 по Киеву), каждые 15 минут
   (на ПК — простой обход без плана), без всплывающих окон. Лог — `attendance.log` рядом со скриптом.

Управление задачей (PowerShell):
```
Start-ScheduledTask 'NURE attendance'                      # запустить сейчас
Get-ScheduledTaskInfo 'NURE attendance'                    # когда запускалась, код возврата
Unregister-ScheduledTask 'NURE attendance' -Confirm:$false # удалить
```

## Telegram

- `TELEGRAM_BOT_TOKEN` — @BotFather → `/mybots` → бот → API Token.
- `TELEGRAM_CHAT_ID` — кому слать: свой числовой ID из [@userinfobot](https://t.me/userinfobot).
  У своего бота обязательно нажми **Start**, иначе он не сможет написать первым.

## Переменные

| Имя | |
|---|---|
| `NURE_USERNAME`, `NURE_PASSWORD` | обязательно; пароль Moodle (не вход через Google) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления, опционально |
| `ATTENDANCE_EXTRA_IDS` / `ATTENDANCE_SKIP_IDS` | id модулей через запятую — добавить/исключить |
| `ATTENDANCE_OFFSETS` | минуты после начала пары, по умолчанию `30` |

`.github/workflows/attendance.yml` оставлен только для ручного запуска — с раннеров GitHub он упрётся в WAF.
